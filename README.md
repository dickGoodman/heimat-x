# HeimatX

Techno-Artfilm von The Art of Techno. Kein Erklärvideo. Bild, Schnitt, Druck.

Der Film liegt nicht in diesem Repo. Rohmaterial ist zu groß und gehört nicht auf GitHub. Hier liegt der Stand, damit das Projekt nicht nur in Chats existiert.

## Stand

- Arbeitstitel: HeimatX
- Ton: Techno, kein Voiceover-Erklärbär
- Bild: dunkel, Rot als Akzent, keine Stock-Ästhetik
- Ausgabe: MP4, wenn ein Schnitt steht

## Ordner, wenn das Material dazu kommt

```text
notes/        Schnittnotizen, Timecodes
stills/       Standbilder, keine Rohclips
exports/      nur kleine Preview-Dateien
```

Rohclips bleiben lokal oder auf einem Drive. GitHub ist für den Plan, nicht fürs Footage.

## Nächster Schnitt

1. Eine Szene, nicht der ganze Film.
2. Ton zuerst, Bild darauf.
3. Watermark dezent, nicht als Bauchbinde.
